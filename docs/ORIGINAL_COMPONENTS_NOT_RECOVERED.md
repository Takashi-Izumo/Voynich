# Original components not recovered

The following original components were not present in the surviving project files and must not be represented as recovered originals:

1. The exact integer-optimization routine used to create all 475--650-tablet candidate inventories.
2. The original 2,000 n-gram holdout configuration stream.
3. The original page-fold seed and smoothing specification for the next-state prediction experiment.
4. The original random seeds used for the 1,000-run shelf fit and 5,000-run shelf attestation experiments.
5. A standalone original program that generated the final 600-tablet inventory from the empirical A-2 fitting events.

What is preserved:

- the exact final 600-tablet inventory;
- the exact 8-tablet Paragraph START inventory;
- the A-2 input and boundary schedule derivable from ZL3b;
- archived 5,000-run n-gram null output;
- the original/surviving Table 2 recomputation code;
- enough information to reconstruct and re-run the final shelf state machine.

The package therefore distinguishes **reproduction of the final fitted machine** from **recovery of the historical fitting code**.
